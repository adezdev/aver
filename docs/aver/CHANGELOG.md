# Changelog

v0.1 — pre-alpha, first pass at the schema. capability switched from a
plain tool count to a sha256 hash after realizing counts can't catch a
1-for-1 swap. Nothing here is stable yet, expect breaking changes.

## Still unresolved

Do vendor namespaces need an actual registry or is informal, npm-scope
style, good enough? Leaning toward informal until this has more than one
user.

For robots, does autonomy=3 need splitting once physical proximity to
people is involved? Or does that belong in policy instead? No strong
opinion yet.
